# Azure Connectors Python SDK

Version 1.0.0 is the first generally available release of `azure-connectors`.
Build type-safe, asynchronous Python integrations with Azure managed connectors
using Azure Core authentication, retries, pagination, and long-running operations.

## Installation

Requires Python 3.10 or later.

```bash
python -m pip install azure-connectors
```

Generated clients and models are available from `azure.connectors.<connector>`.
Clients are async-only and accept a caller-owned async Azure Identity credential
or an Azure Core API key credential.
